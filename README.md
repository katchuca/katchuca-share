# `katchuca-share` — Acervo Público por Segmentos

Repositório público oficial com as **skills**, ferramentas, prompts e materiais gratuitos liberados nas postagens de **kaTcHuca** no X, YouTube e Instagram.

Acesse o hub para desbloquear pacotes `.zip`, arquivos individuais e recomendações por link de post:
**https://share.katchuca.workers.dev**

## Segmentos

1. [`skill/`](./skill/) — Skills instaláveis para agentes de IA (Antigravity, Claude Code, Cursor, Codex, etc.)
2. [`tool/`](./tool/) — Utilitários, scripts e automações práticas
3. [`prompt/`](./prompt/) — Prompts estruturados e frameworks de produção
4. [`article/`](./article/) — Materiais complementares de artigos publicados no Substack
5. [`course/`](./course/) — Recursos abertos de apoio aos cursos
6. [`app/`](./app/) — Projetos e documentações públicas de aplicativos
7. [`game/`](./game/) — Recursos e protótipos de jogos

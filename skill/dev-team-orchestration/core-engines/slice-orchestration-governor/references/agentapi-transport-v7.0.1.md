# AgentAPI Legacy Transport Contract

This contract governs the optional `AGENTAPI_ONLY` transport mode when persistent external chat sessions are explicitly selected instead of default `NATIVE_SUBAGENTS`. Avoid older patterns that pass `--title`, accept arbitrary output as an ID, equate exit code zero with delivery, or treat a populated registry alone as runtime verification.

All specialists remain independent persistent Antigravity conversations. They are not native subagents. Each newly created or migrated role must have a project-bound hook bootstrap acknowledgement before task dispatch. Never silently replace a missing/unconfirmed binding with another chat.

Host-provided live endpoint, CSRF token and project ID are required and must not be copied into the project. A mock transport passing local tests is not live-host acceptance. The wrapper's delivery acknowledgement is not proof of model execution or completion; the existing `swarm-complete`/phase-outcome contract remains authoritative for task progress.

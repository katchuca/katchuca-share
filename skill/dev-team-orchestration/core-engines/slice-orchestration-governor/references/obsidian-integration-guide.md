# Obsidian Integration Guide — v6.1

Obsidian is optional. The v6.1 Engineering Vault is plain Markdown and stable file paths, so it can be opened directly as an Obsidian vault when project policy allows.

Recommended project-local location: `.agy-vault/`.

The Vault uses folders and generated indexes for requirements, decisions, architecture, learnings, research, risks, workstreams, tasks and artifacts. Canonical product documents remain authoritative and are linked through `sourceRef`; do not copy entire product specs into the Vault.

The legacy Second Brain `vault-init/compile/audit` workflow may coexist for broader knowledge compilation. The Agy Engineering Vault is the operational engineering/requirements memory used by v6.1.

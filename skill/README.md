# Segmento 01 — Skills (`skill/`)

Cada skill fica em sua própria subpasta em `kebab-case`, por exemplo:

- `skill/_template/` (modelo base para novas skills)
- `skill/<slug-da-skill>/`

Estrutura padrão de cada pasta:
- `SKILL.md` — instruções, regras e contexto da skill
- `README.md` — visão rápida de uso e instalação
- `scripts/` ou `references/` — arquivos auxiliares quando necessários
